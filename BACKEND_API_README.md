# 🔌 Kongu Aura Backend REST API Reference & Integration Guide
**Service Port:** `3000` | **Base URL:** `http://localhost:3000` | **Protocol:** HTTP/1.1  
**Architecture:** Zero-dependency, event-driven Node.js REST API with analytical compute engines.

---

## 1. System Health & Metadata Endpoints

Returns system operational state, process uptime, and loaded outlet count.
* **Response (200 OK):**
```json
{
  "status": "ok",

}
```

## 2. Analytical & Statistical Compute Engines

### `GET /api/results`
Returns the complete empirical payload generated by the Monte Carlo simulation and econometric pipeline.
* **Response Structure:**
  - `dirtyDataAudit`: Breakdown of 300,000 records (disguised no-shows, missing IDs, taxonomies).
  - `srm`: Observed counts, Pearson $\chi^2$ statistic, and $p$-value.
  - `balance`: Standardized Mean Differences (SMD) for all baseline covariates.
  - `abTestResults`: Primary RPV lift, Welch's t-test, and 10,000-resample Bootstrap CIs.
  - `didAnalysis`: 2x2 DiD decomposition and 12-window dynamic event study.
  - `segmentation`: Heterogeneous treatment effects across 12 subgroups.
  - `cuped`: Empirical covariance parameters, variance reduction %, and days saved.
  - `powerAnalysis`: Analytical sample size and cluster design effect calculations.

Dynamic Sample Ratio Mismatch (SRM) diagnostic engine. Evaluates whether observed assignment counts diverge from the expected traffic split.

* **Request Body:**
```json
{
  "control_count": 23031,
  "treatment_count": 23304,
  "ratio": 0.5
}
```

## 3. Data Query & Export Endpoints

### `GET /api/appointments`
Filterable, paginated transaction explorer returning raw vs cleaned appointment fields.
* **Query Parameters:**
  - `page` (default: 1)
  - `limit` (default: 20)
  - `outlet` (e.g. `OUT-01`)
  - `category` (e.g. `Hair Services`)
  - `variant` (`CONTROL` or `TREATMENT`)
  - `status` (`COMPLETED`, `NO_SHOW`, `NO_SHOW_DISGUISED`, `ADVANCE_CANCELLATION`)
  - `search` (Search by Appointment ID, Client ID, or Service Name)
* **Response:**
```json
{
  "page": 1,
  "limit": 20,
  "total": 5000,
  "totalPages": 250,
  "data": [
    {
      "appointment_id": "APT-2023-100001",
      "outlet_name": "R.S. Puram Flagship",
      "clean_client_id": "CL-24156",
      "stylist_tier": "Senior",
      "raw_service_name": "Signature Men Cut & Styling Lounge",
      "clean_category": "Hair Services",
      "derived_status": "COMPLETED",
      "total_spend_inr": 2450,
      "ab_variant": "TREATMENT"
    }
  ]
}
```

### `GET /api/export/csv`
Streams a formatted CSV export of cleaned transaction records for offline analysis in Excel, R, or Python.
